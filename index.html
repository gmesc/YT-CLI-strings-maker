Tutorial

Aprire il terminale

Questa SPA prepara una stringa yt-dlp pronta da copiare. Il download parte solo quando apri il terminale, incolli il comando generato e premi Invio.

Prima di iniziare

Servono yt-dlp e, per conversioni audio/video, anche ffmpeg. Se usi Homebrew su macOS, puoi installarli con questo comando:

brew install yt-dlp ffmpeg

Su Windows, se usi winget, puoi provare questi comandi in PowerShell:

winget install yt-dlp
winget install --id Gyan.FFmpeg

Istruzioni aggiornate: installazione yt-dlp e download ffmpeg.

macOS

  1. Premi Cmd + Spazio per aprire Spotlight.
  2. Scrivi Terminale.
  3. Premi Invio.
  4. Incolla il comando generato con Cmd + V.
  5. Premi Invio per avviare il download.

Windows

  1. Apri il menu Start.
  2. Cerca PowerShell oppure Terminale.
  3. Aprilo e, nella SPA, seleziona PowerShell nel campo Terminale.
  4. Incolla il comando generato con Ctrl + V.
  5. Premi Invio per avviare il download.

Dove vengono salvati i file

Usa il campo Cartella download nella sezione Input. Il builder aggiunge il flag -P, quindi non devi cambiare cartella nel terminale prima di lanciare il comando.
